description: Connect to Microsoft 365 / Microsoft Graph (Exchange, SharePoint, Teams, Entra ID)
argument-hint: "[service: graph | exchange | sharepoint | teams]"
allowed-tools: Bash, Read
---

Help the user connect to Microsoft 365 services. The target service is
"$ARGUMENTS" (default to Microsoft Graph if empty).

Pick the right connection flow:

- **graph** (Entra ID / users / groups): `Connect-MgGraph -Scopes "User.Read.All"`
  then `Get-MgContext`. Requires the `Microsoft.Graph` PowerShell module.
- **exchange** (Exchange Online): `Connect-ExchangeOnline -UserPrincipalName <upn>`
  then `Get-ConnectionInformation`. Requires the `ExchangeOnlineManagement` module.
- **sharepoint**: `Connect-PnPOnline -Url <site-url> -Interactive` then
  `Get-PnPContext`. Requires the `PnP.PowerShell` module.
- **teams**: `Connect-MicrosoftTeams` then `Get-CsTenant`. Requires the
  `MicrosoftTeams` module.

Steps:

1. Check whether the required module is installed
   (`Get-Module -ListAvailable <module>`); if not, show the
   `Install-Module <module> -Scope CurrentUser` command but do not install
   without confirmation.
2. Run the connect command for the chosen service, explaining that
   interactive / browser-based sign-in may be required.
3. Verify the connection with the corresponding context cmdlet and report
   the signed-in account and tenant.
